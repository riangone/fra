⚡ 本システムの主要技術スタック

1. LangGraph オーケストレーション

StateGraph による状態追従、引用一致率が 70% を下回った場合の条件付きエッジ（should_retry）による自動自己修正ループ。

2. Model Context Protocol (MCP)

Anthropic 標準 MCP 規格に準拠した独立ツールサーバー。東証コード・最新株価・PER・PBR・ROE・バリュートラップ判定の外部ツール提供。

3. ハイブリッド RRF 検索エンジン

日本語 CJK Bi-gram + 金融複合数値トークナイズによる BM25 Okapi と Dense Vector を順位融合（$k=60$）。Elasticsearch 8.x Kuromoji および GCP Discovery Engine（Vertex AI Search）拡張アダプタ対応。

4. 文単位引用一致率監査器

生成文中のすべての主張を分解し、文献 Chunk / MCP データのトークン包含を検証。Consistency Rate、Precision、Recall を自動定量化。

5. 夜間非同期開示バッチ基盤

東証大引け（15:00）後の適時開示ラッシュを想定した asyncio.Semaphore 並行制御による自律分析・研報生成パイプライン。

6. クラウドネイティブ IaC & 可観測性

AWS Lambda 预置并发冷启动排除 + GCP Discovery Engine / Vertex AI + W3C TraceContext & Datadog SLO 監視。

7. LLM Provider フォールバックチェーン

ローカル AI CLI（claude / antigravity / opencode、API Key 不要）を既定・最優先とし、llm_cloud_fallback_order を設定した場合のみ Azure OpenAI（AzureOpenAI client）または Google Vertex AI（google-genai、ADC 認証）へ opt-in 兜底。
